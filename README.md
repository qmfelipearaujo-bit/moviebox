# MovieBox Private v0.5

Versao de diagnostico para Windows.

1. Copie o arquivo `.env` da versao anterior para esta pasta.
2. Dê dois cliques em `CRIAR_APK.bat`.
3. O CMD aberto pelo projeto nao fecha automaticamente, mesmo se houver erro.
4. Se gerar corretamente, o arquivo final sera `MovieBox-Private-debug.apk` na pasta principal.

O APK intermediario tambem fica em:
`android\app\build\outputs\apk\debug\app-debug.apk`
